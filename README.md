# 🛸 Rick and Morty Landing

Landing page temática inspirada en el universo de Rick and Morty. Diseñada como ejercicio visual y estructural con enfoque en diseño estático.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

---

## 📌 Descripción

Este proyecto es una landing page básica que presenta contenido gráfico y estilizado relacionado con Rick and Morty. Ideal para practicar estructura HTML, estilos personalizados y organización de recursos visuales.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**: estructura semántica
- **CSS3**: estilos personalizados
- **Imágenes y recursos visuales**: organizados en carpeta `src/`

---

## ✨ Secciones

Introducción, galería de personajes, capítulos y temporadas destacadas, videos y formulario de contacto, con navegación por anclas desde el encabezado.

## ⚙️ Cómo verlo

Abrí `index.html` en el navegador. No necesita instalación.

> Proyecto de práctica académica sin fines comerciales. Rick and Morty y sus personajes pertenecen a sus respectivos dueños.
