# 🛸 Rick and Morty Landing

Landing page temática inspirada en el universo de Rick and Morty. Diseñada como ejercicio visual y estructural con enfoque en diseño estático.

---

## 📌 Descripción

Este proyecto es una landing page básica que presenta contenido gráfico y estilizado relacionado con Rick and Morty. Ideal para practicar estructura HTML, estilos personalizados y organización de recursos visuales.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**: estructura semántica
- **CSS3**: estilos personalizados
- **Imágenes y recursos visuales**: organizados en carpeta `src/`
